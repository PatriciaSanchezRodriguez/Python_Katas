# 🐍 Proyecto Lógica - Katas de Python

## Descripción

Este proyecto contiene la resolución de una serie de katas y ejercicios de lógica en Python. El objetivo es practicar los conceptos fundamentales del lenguaje, mejorar la capacidad de resolución de problemas y afianzar conocimientos de programación.

Los ejercicios abarcan temas como:

- Funciones
- Listas, tuplas y diccionarios
- Programación funcional (`map`, `filter`, `reduce`)
- Funciones lambda
- Manejo de excepciones
- Recursividad
- Programación orientada a objetos
- Condicionales y estructuras de control

El proyecto está basado en el documento EnunciadoDataProjectPython.pdf.

## Tecnologías utilizadas

- Python 3

## Contenido

Entre los ejercicios realizados se encuentran:

- Conteo de frecuencia de letras.
- Operaciones con listas mediante `map()`.
- Filtrado de datos utilizando `filter()`.
- Uso de `reduce()` para operaciones acumulativas.
- Cálculo de factoriales recursivos.
- Tratamiento de errores y excepciones.
- Comprobación de anagramas.
- Enmascarado de cadenas de texto.
- Gestión de usuarios bancarios mediante clases.
- Implementación de una clase Árbol.
- Cálculo de áreas geométricas.
- Ejercicios de lógica y validación de datos.

## Cómo ejecutar el proyecto

1. Clonar el repositorio:

```bash
git clone https://github.com/tu-usuario/proyecto-python.git
```

2. Acceder a la carpeta:

```bash
cd proyecto-python
```

3. Ejecutar el archivo deseado:

```bash
python ejercicio_01.py
```

## Objetivo

El propósito de este proyecto es practicar Python mediante ejercicios de dificultad progresiva para reforzar la lógica de programación y adquirir soltura con las principales herramientas del lenguaje.
